# Swiggy Restaurant Analysis Using SQL

## Project Overview

This project analyses Swiggy restaurant data using MySQL.

The objective is to understand restaurant distribution,
popular food types, restaurant branches, ratings and delivery
time patterns across different locations.

## Dataset

The dataset contains restaurant information such as:

- Hotel Name
- Location
- Rating and Delivery Time
- Food Type
- Offer

## Tools Used

- MySQL
- MySQL Workbench
- GitHub

## SQL Skills Used

- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- Aggregate Functions
- COUNT()
- AVG()
- String Functions (SUBSTRING_INDEX)
- Data Cleaning
- Filtering

## Business Questions

1. Which location has the most restaurants?
2. What is the most popular food type?
3. Which restaurant chain/branch has the most locations?
4. Which locations have the highest average rating?
5. Which locations have the fastest average delivery time?
